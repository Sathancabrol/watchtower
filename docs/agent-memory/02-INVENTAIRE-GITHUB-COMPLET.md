## Modèle de mise à jour

1. Lire le SHA de `watchtower/main` et les branches ; vérifier les PR et les CI.
2. Rafraîchir les arbres GitHub (`/git/trees/{sha}?recursive=1`) et comparer `path`, `sha`, `size`.
3. Recalculer la matrice, **sans effacer les instantanés historiques**.
4. Pour chaque capacité spécifique, lire le code et le test correspondant avant d'écrire « fonctionnel ».
5. Ne jamais mettre dans ce dépôt public des secrets, des données privées ou des résultats d'analyse d'une personne.
