## Contrats et précautions

- Watchtower : lieu, temps, fait et source ; **ne pas déduire une propriété cognitive humaine de capteurs publics**.
- HCSM : versions de modèles et validations explicites à prouver indépendamment.
- Research Engine : graphe de provenance et recherche utilisable seulement après interopérabilité testée.
- Chronos : animations et narration ne sont pas le runtime CRONOS (ne pas confondre les noms).
- Les branches de handoff sont distinctes de leurs branches principales et nécessitent consolidation prudente.
