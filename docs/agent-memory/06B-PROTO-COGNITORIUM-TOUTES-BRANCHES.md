- Le prototype n'est pas la même pile que Watchtower (interface TS/React/Three versus JS/Cesium) : travailler par **schémas d'échange**.
- Une branche portant une amélioration de liens de preuves n'est pas nécessairement fusionnée sur `main`.
- Ne pas réutiliser les états de profil utilisateur dans la carte publique sans consentement explicite.
